# Auth + Dashboard App

Aplicación web construida con **React + TypeScript** que implementa autenticación de usuarios, manejo de estado global y un dashboard con UI moderna.

---

## Tecnologías utilizadas

* React (Vite)
* TypeScript
* Tailwind CSS
* Zustand (manejo de estado)
* Supabase (autenticación)

---

## Funcionalidades

* Inicio de sesión con email y contraseña
* Manejo de sesión global con Zustand
* Rutas protegidas
* Dashboard básico
* UI responsive
* Sidebar desplegable
* Modal personalizado (popup)

---

## Instalación

Clona el repositorio:

```
git clone https://github.com/luisleal94/gestionUsuarios.git
```

Instala dependencias:

```
npm install
```

Ejecuta el proyecto:

```
npm run dev
```
